# Лабораторная работа №4

## Разработка аутентификации и авторизации веб-приложения "Электрические нагрузки автомобиля"

## Цель работы

Закрепление навыков разработки механизмов аутентификации и авторизации в веб-приложении, работы с JWT-токенами, Redis blacklist и документирования REST API с использованием Swagger.

В ходе выполнения работы была реализована система аутентификации пользователей, разграничение доступа к методам веб-сервиса и механизм отзыва JWT-токенов.

## Redis blacklist

В ходе лабораторной работы был реализован механизм отзыва JWT-токенов.

При выполнении выхода пользователя:

- JWT не удаляется физически;
- идентификатор токена `jti` добавляется в Redis blacklist;
- для записи устанавливается TTL до окончания срока действия JWT;
- при каждом защищённом запросе выполняется проверка отсутствия токена в blacklist.

В Redis сохраняется информация вида:

```text
jwt:blacklist:<jti>
```

Со значением, содержащим информацию о пользователе.

## Диаграмма последовательности

Для описания взаимодействия компонентов системы была разработана UML-диаграмма последовательности.

В диаграмме используются три участника:

- фронтенд;
- домен пользователей;
- домен электрических нагрузок.

На диаграмме представлены основные операции:

- аутентификация пользователя;
- получение списка электрических нагрузок;
- создание черновика;
- получение черновика;
- публикация нагрузки;
- получение элемента ленты;
- переход к следующему элементу;
- установка отметки "Нравится".

Для сообщений диаграммы были заданы ссылки `signature` на соответствующие операции диаграммы классов.

# Структура API

Основные методы работы с электрическими нагрузками:

- `GET /api/electric-car-loads`\
  Получение списка опубликованных электрических нагрузок

- `GET /api/electric-car-loads/feed`\
  Получение элемента ленты

- `GET /api/electric-car-loads/draft`\
  Получение черновика текущего пользователя

- `POST /api/electric-car-loads`\
  Создание нового черновика

- `PUT /api/electric-car-loads/{id}`\
  Публикация электрической нагрузки

- `DELETE /api/electric-car-loads/{id}`\
  Логическое удаление электрической нагрузки

- `POST /api/electric-car-loads/{id}/like`\
  Установка или снятие отметки "Нравится"

---

# Методы пользователей

- `POST /api/users/register`\
  Регистрация нового пользователя

- `POST /api/users/auth`\
  Аутентификация пользователя и получение JWT

- `POST /api/users/logout`\
  Деавторизация пользователя и добавление JWT в Redis blacklist
