# Лабораторная работа №4

## Разработка аутентификации и авторизации веб-приложения "Электрические нагрузки автомобиля"

## Цель работы

Закрепление навыков разработки механизмов аутентификации и авторизации в веб-приложении, работы с JWT-токенами, Redis blacklist и документирования REST API с использованием Swagger.

В ходе выполнения работы была реализована система аутентификации пользователей, разграничение доступа к методам веб-сервиса и механизм отзыва JWT-токенов.

---

# Полученные знания и навыки

## Аутентификация пользователей

В ходе выполнения работы были закреплены навыки:

- регистрации пользователей;
- проверки логина и пароля;
- безопасного хранения паролей с использованием bcrypt;
- формирования JWT-токенов;
- передачи JWT в HTTP-заголовке:
  - `Authorization: Bearer <jwt>`;
- получения идентификатора текущего пользователя из токена.

---

## Авторизация

Были изучены и применены:

- разграничение доступа к API-методам;
- проверка наличия JWT перед выполнением защищённых операций;
- использование middleware для проверки токена;
- различие между:
  - публичными методами;
  - методами, доступными только авторизованному создателю;
- обработка ошибок авторизации:
  - `401 Unauthorized`;
  - отказ в выполнении защищённой операции без JWT.

---

## JWT

Закреплены знания:

- структуры JSON Web Token;
- формирования JWT после успешной аутентификации;
- использования стандартных полей токена;
- хранения в JWT:
  - идентификатора пользователя;
  - имени пользователя;
  - времени выдачи;
  - времени окончания действия;
  - уникального идентификатора токена `jti`;
- проверки подписи и срока действия JWT.

---

## Redis blacklist

В ходе лабораторной работы был реализован механизм отзыва JWT-токенов.

При выполнении выхода пользователя:

- JWT не удаляется физически;
- идентификатор токена `jti` добавляется в Redis blacklist;
- для записи устанавливается TTL до окончания срока действия JWT;
- при каждом защищённом запросе выполняется проверка отсутствия токена в blacklist.
