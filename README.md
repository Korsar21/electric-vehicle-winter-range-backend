# Лабораторная работа №1
## Разработка интерфейса веб-приложения "Электрические нагрузки автомобиля"

## Цель работы

Закрепление навыков разработки пользовательских интерфейсов веб-приложений с использованием HTML и CSS, а также создание структуры страниц серверного приложения на основе HTML-шаблонов.

В ходе выполнения работы был разработан интерфейс приложения для отображения электрических нагрузок автомобиля в зимних условиях эксплуатации.

---

# Полученные знания и навыки

## HTML-шаблоны

В ходе выполнения работы были закреплены навыки:

- создания структуры HTML-страниц;
- работы с HTML-шаблонами серверного приложения;
- организации пользовательского интерфейса из отдельных компонентов;
- использования динамических данных в шаблонах;
- создания страниц:
  - лента электрических нагрузок;
  - плиточное представление нагрузок;
  - страница добавления нагрузки.

---

## CSS-стилизация

Были изучены и применены:

- создание единого визуального стиля приложения;
- работа с CSS-классами;
- настройка:
  - цветов;
  - размеров элементов;
  - отступов;
  - расположения блоков;
  - кнопок и панелей интерфейса;
- создание адаптивного отображения страниц.

---

## Серверный рендеринг

Закреплены знания:

- использования HTML-шаблонов в Go-приложении;
- передачи данных из backend в интерфейс;
- формирования представления объектов через структуры данных;
- организации взаимодействия обработчиков и страниц приложения.

---

## Разработка интерфейса предметной области

Создан интерфейс приложения:

- "Электрические нагрузки автомобиля";
- отображение мощности потребления нагрузки;
- отображение приоритета нагрузки;
- фильтрация по максимальной мощности;
- отображение изображений и видеоматериалов;
- создание карточек нагрузок.

---

# Структура приложения

Основные страницы:

- `/electric-car-loads/feed`  
  Лента электрических нагрузок автомобиля

- `/electric-car-loads/add`  
  Добавление новой нагрузки

- `/electric-car-loads`  
  Плиточное представление нагрузок
